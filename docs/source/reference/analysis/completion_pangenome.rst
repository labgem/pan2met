Pangenome pathway strain-wise completion
========================================

After **pan2met** metabolic pathway predictions, the predicted metabolic pathway might be complete, with all their reactions being either spontaneous, or being catalyzed by an enzyme in the strain.

**pan2met** includes a script to compute the completion of the pathway in each strain of the pangenome.

The completion of a pathway is the number of catalyzed non spontaneous reactions over the total number of non spontaneous reactions of a pathway.

To get a completion matrix of the metabolic pathways, we can use the script ``completion_pangenome.py``:

.. code:: bash

    python3 -m pan2met.analysis.completion_pangenome \
          --ppanggolin-dir ppanggolin/output \
          --pathways pathway.list \
          --gene-reactions gene_reaction.tsv \
          --prefix "completion_"

This script expects the provided ``--ppanggolin-dir`` output directory to contain the following files, generated by ``ppanggolin write_pangenome`` command in PPanGGOLiN:

.. csv-table:: ``ppanggolin/output`` expected content files
   :header: "File", "Content"
   :widths: 15, 10

            gene_presence_absence.Rtab,"gene presence absence Boolean matrix"
            functional_modules.tsv,pangenome functional modules (module identifier and gene family identifier)
            partitions/persistent.txt, gene families in the persistent pangenome partition
            partitions/shell.txt, gene families in the shell pangenome partition
            partitions/cloud.txt, gene families in the cloud pangenome partition


The ``completion_pangenome`` will produce three files prefixed with the prefix given in ``--prefix`` option:

- ``<prefix>_pathway_completion_by_strain.tsv`` -- a completion matrix for each pathway in each strain.
- ``<prefix>_pathway_completion_wo_orphan_by_strain.tsv`` -- a completion matrix for each pathway in each strain, ignoring the orphan reactions.
- ``<prefix>_reaction_presence_absence.Rtab`` -- a .Rtab format presence absence Boolean matrix reporting whether a given reaction catalysis is found in a given strain.

The pathway completion matrix table have the following columns:

.. csv-table:: Columns of the pathway completion matrix
   :header: "Column", "Content"
   :widths: 15, 10


            pathway,"the identifier of the pathway"
            pathway name,"the name of the pathway, if available in the knowledgebase"
            nb reactions,"number of reactions in the pathway"
            families,"number of gene families involved in the pathway"
            persistent %,"percentage of the families in the persistent pangenome partition"
            shell %,"percentage of the families in the shell pangenome partition"
            cloud %,"percentage of the families in the cloud pangenome partition"
            "modules (reaction cov.)","a comma separated value list of module identifier and the coverage of the pathway in the module (ratio of the number of reaction in the module over the number of reaction with a families in the pangenome)"
            "global completion","global pangenome completion"
            "max completion","maximum strain-wise completion"
            "strains completions columns", "for each strain, the completion value of the pathway in the strain"
